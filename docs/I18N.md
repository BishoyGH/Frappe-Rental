# Translations and RTL (T57)

- Server strings use `_()`, the staff and customer app uses `__()`. Both read `frappe_rental/translations/<lang>.csv` (source, translation).
- Add a language: copy `ar.csv` to `<code>.csv` and translate the second column. Keep the `{0}` placeholders.
- `python scripts/extract_messages.py` lists every string. `--check ar` fails when a customer-facing string has no Arabic text (runs in CI).
- The page `lang` and `dir` come from the session language. Arabic, Hebrew, Persian and Urdu are right to left. Use `ms-`, `me-`, `ps-`, `pe-`, `text-start`, `text-end`, `border-s`, `border-e` in components, never left/right.
- Strings built from a variable (statuses, step names) are not found by the extractor; add them to the CSV by hand.
